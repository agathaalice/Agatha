# 📖 Sobre o Projeto

Este projeto foi desenvolvido como parte do desafio da DIO, utilizando o NotebookLM como ferramenta de apoio aos estudos.

O objetivo foi criar um caderno temático sobre **Engenharia de Prompts aplicada à Inteligência Artificial Generativa**, reunindo materiais confiáveis, realizando testes com diferentes prompts e produzindo um guia de estudos para consultas futuras.

Além da utilização da IA, o projeto também demonstra organização, documentação e boas práticas de curadoria de conteúdo.

---

# 🎯 Objetivos

- Aprender os fundamentos da Engenharia de Prompts.
- Explorar o funcionamento do NotebookLM.
- Organizar conteúdos em um único ambiente.
- Criar um guia de consulta rápida.
- Desenvolver habilidades de pesquisa utilizando IA.
- Documentar todo o processo de aprendizagem.

# 📖 Miniguia de Estudos

## O que é IA Generativa?

É uma área da Inteligência Artificial capaz de criar novos conteúdos, como textos, imagens, vídeos, músicas e códigos, utilizando grandes modelos treinados com enormes quantidades de dados.

---

## O que é um Prompt?

Prompt é a instrução enviada para a Inteligência Artificial.

Quanto melhor for o prompt, melhor será a resposta.

---

## O que é Engenharia de Prompts?

É a prática de construir perguntas inteligentes para extrair respostas mais completas, corretas e úteis da IA.

---

## Boas práticas

✔ Seja específico.

✔ Informe o contexto.

✔ Defina um objetivo.

✔ Informe o formato esperado.

✔ Peça exemplos.

✔ Defina o público-alvo.

✔ Limite o tamanho da resposta.

---

## Estrutura de um bom Prompt

```
Contexto

+

Objetivo

+

Formato

+

Restrições

+

Exemplos
```

# 📚 Glossário

| Conceito | Definição |
|-----------|-----------|
| IA Generativa | Inteligência Artificial capaz de criar conteúdo novo. |
| Prompt | Instrução enviada para a IA. |
| LLM | Large Language Model. |
| Token | Unidade utilizada pelo modelo para interpretar textos. |
| Engenharia de Prompts | Técnica de escrever melhores instruções para IA. |
| Contexto | Informações adicionais fornecidas à IA. |
| Output | Resposta produzida pelo modelo. |
